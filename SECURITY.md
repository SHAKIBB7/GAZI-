# Security Policy

## Supported Versions

We provide security updates and patches for the following versions of the GAZI Sports Platform:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is paramount for GAZI Sports, especially regarding customer privacy, order financials, authentication tokens, and inventory integrity.

If you discover a security vulnerability in this project:

1. **Do not create a public GitHub issue.**
2. Send an email to the security team at **`security@gazisports.com`** or contact the lead maintainer directly.
3. Include detailed information:
   - Type of vulnerability (e.g., Auth bypass, SQL/NoSQL injection, XSS, SSRF, Concurrency race condition).
   - Step-by-step reproduction instructions or proof-of-concept (PoC).
   - Potential impact of the vulnerability.
   - Recommended remediation if known.

### Response Timeline
- **Initial acknowledgment**: Within 24-48 hours.
- **Triage and severity assessment**: Within 3 business days.
- **Fix rollout and coordinated disclosure**: As swiftly as possible based on severity.

Thank you for responsibly reporting vulnerabilities and helping keep our community safe.
